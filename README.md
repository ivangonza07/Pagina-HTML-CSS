# Pagina-HTML-CSS

## 📖 Descripción

Página web estática educativa desarrollada con HTML y CSS. El sitio está escrito en **euskera** y contiene información sobre hardware, redes y sistemas operativos. Fue creada como proyecto de aprendizaje.

## 🚀 Características

- **Diseño simple y educativo** - Estructura clara con navegación entre secciones
- **Contenido en euskera** - Todo el contenido está en idioma vasco
- **Secciones informativas**:
  - 🖥️ **Hardware** - Componentes y conceptos de hardware
  - 🌐 **Sareak (Redes)** - Configuración de redes y cableado
  - 💿 **Sistema Eragileak (Sistemas Operativos)** - Instalación y configuración de sistemas operativos

## 📋 Requisitos

- Navegador web moderno (Chrome, Firefox, Edge, etc.)
- No requiere servidor ni dependencias adicionales

## 🛠️ Tecnologías

- **HTML5** - Estructura del sitio
- **CSS3** - Estilos y diseño

## 📁 Estructura del Proyecto

```
Pagina-HTML-CSS/
├── index.html              # Página principal
├── Hardware.html           # Sección de Hardware
├── Sareak.html             # Sección de Redes
├── Sistema-eragileak.html  # Sección de Sistemas Operativos
├── estilos.css             # Hoja de estilos
└── IRUDIAK/                # Carpeta de imágenes
    ├── logotolosaldea.jpg
    ├── gifg.gif
    ├── ordenador.jpg
    ├── patch.jpg
    └── ... (imágenes del proyecto)
```

## 📖 Uso

Simplemente abre el archivo `index.html` en tu navegador:

```bash
# En Windows
start index.html

# En macOS/Linux
open index.html
```
